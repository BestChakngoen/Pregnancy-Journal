| 4. การนอนตะแคงซ้ายขณะพักผ่อนช่วยลดการกดทับหลอดเลือดดำใหญ่และเพิ่ม การไหลเวียนเลือดไปเลี้ยงรกได้ดีขึ้น | √ |   |
| 5. การลดอาหารรสเค็ม หลีกเลี่ยงเครื่องดื่มแอลกอฮอล์และบุหรี่ และควบคุม น้ำหนักอย่างเหมาะสม เป็นส่วนหนึ่งของการดูแลตนเอง | √ |   |
| 6. หญิงตั้งครรภ์ที่มีความเสี่ยงควรหลีกเลี่ยงการออกกำลังกายหรือการเคลื่อนไหว ร่างกายทุกชนิด |   | √ |
| 7. หากรู้สึกว่าลูกดิ้นลดลงอย่างผิดปกติ หญิงตั้งครรภ์ควรรอดูอาการก่อนและไม่ จำเป็นต้องแจ้งบุคลากรทางการแพทย์ |   | √ |
| 8. หญิงตั้งครรภ์สามารถซื้อยามารับประทานเองได้ หากคิดว่าตนเองมีความเสี่ยงต่อ ภาวะความดันโลหิตสูง |   | √ |
| 9. หญิงตั้งครรภ์ควรเลือกรับประทานอาหารที่มีโปรตีน เช่น เนื้อสัตว์ไม่ติดมัน นม ไข่ ถั่วเหลือง ฯลฯ | √ |   |
| 10. หากหญิงตั้งครรภ์รับประทานอาหารไม่ครบ 5 หมู่ อาจส่งผลกระทบต่อสุขภาพ ของทั้งมารดาและทารกในครรภ์ได้ | √ |   |

## แบบประเมินความเสี่ยงภาวะความดันโลหิตสูงขณะตั้งครรภ์

หมายเหตุ: แบบประเมินนี้ใช้เพื่อการคัดกรองความเสี่ยงเบื้องต้น ไม่สามารถใช้ยืนยันการวินิจฉัยโรคได้ หากพบว่ามี ความเสี่ยงหรือมีอาการผิดปกติ ควรได้รับการประเมินเพิ่มเติมโดยบุคลากรทางการแพทย์

| คำถาม | ใช่ | ไม่ใช่ |
| --- | --- | --- |
| ส่วนที่ 1 ข้อมูลพื้นฐานและประวัติการตั้งครรภ์ (ข้อละ 1 คะแนน) |   |   |
| 1. อายุ 35 ปีขึ้นไป |   |   |
| 2. เป็นการตั้งครรภ์ครั้งแรก |   |   |
| 3. เคยมีประวัติทารกเจริญเติบโตช้าในครรภ์ |   |   |
| 4. ตั้งครรภ์แฝด |   |   |
| 5. ดัชนีมวลกาย มากกว่า 30 kg/m2 |   |   |
| ส่วนที่ 2 โรคประจำตัว (ข้อละ 5 คะแนน) |   |   |
| 6. ก่อนตั้งครรภ์เคยมี ความดันโลหิตสูงเรื้อรัง |   |   |
| 7. เคยมีประวัติความดันโลหิตสูงขณะตั้งครรภ์/ครรภ์เป็นพิษในการตั้งครรภ์ ครั้งก่อน |   |   |
| 8. เคยเป็นโรคเบาหวาน ก่อนหรือขณะตั้งครรภ์ |   |   |
| 9. โรคไตเรื้อรัง |   |   |
| 10. โรคภูมิต้านทานตนเอง (SLE) |   |   |
| ส่วนที่ 3 ประวัติครอบครัว (ข้อละ 5 คะแนน) |   |   |
| 11. มารดาหรือพี่สาว เคยมีประวัติครรภ์เป็นพิษหรือความดันโลหิตสูงขณะ ตั้งครรภ์ |   |   |
| ส่วนที่ 4 อาการระหว่างตั้งครรภ์ (ข้อละ 5 คะแนน) |   |   |
| 12. ความดันโลหิต ตั้งแต่ 140/90 mmHg. |   |   |
| 13. มีอาการปวดศีรษะ / ตาพร่ามัว/ เจ็บแน่นลิ้นปี่ |   |   |
| 14. มีอาการบวมที่ใบหน้าหรือมือ/ ขาและเท้า/ น้ำหนักเพิ่มขึ้นเฉียบพลัน เกิน 1 กก./สัปดาห์/ตรวจพบโปรตีนในปัสสาวะ |   |   |
| รวมคะแนน |   |   |

## เกณฑ์การคัดกรองความเสี่ยง

0–4 คะแนน: หมายถึง มีความเสี่ยงต่ำ ต่อการเกิดภาวะความดันโลหิตสูงขณะตั้งครรภ์

ตั้งแต่ 5 คะแนนขึ้นไป: หมายถึง มีความเสี่ยงสูง ต่อการเกิดภาวะความดันโลหิตสูงขณะตั้งครรภ์

และควรได้รับการติดตามและประเมินเพิ่มเติมโดยบุคลากรทางการแพทย์


## แบบประเมินความพึงพอใจต่อการใช้แอปพลิเคชั่น

คำชี้แจง: โปรดทำเครื่องหมาย ลงในระดับความคิดเห็นที่ตรงกับความรู้สึกของท่านมากที่สุด

## เกณฑ์การให้คะแนน

- 5 = พึงพอใจมากที่สุด

- 4 = พึงพอใจมาก

- 3 = พึงพอใจปานกลาง

- 2 = พึงพอใจน้อย

- 1 = พึงพอใจน้อยที่สุด
