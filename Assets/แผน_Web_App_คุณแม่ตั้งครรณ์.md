# แผน Web App คุณแม่ตั้งครรณ์

**แผนงานสำหรับฟีเจอร์ทั้งหมด**
1. ระบบ log in แบบ anonymous โดยใช้ firebase
- สามารถเข้าบันชีเดิมได้โดยการใช้ชื่อเดิม และป้องกันชื่อซ้ำกัน

2. deploy ผ่าน Vercel 

3. ระบบเก็บข้อมูลส่วนตัว
- ชื่่อ
- อายุ
- อายุครรณ์
- จำนวณครั้งการตั้งครรณ์

4. ประเมินความเสี่ยง 
- รวมคะแนน
- สรุปผล
- สรุปความเสี่ยงของคนไข้แต่ละข้อ

5. ส่วนความรู้เสริม 
- pre test วัดความรู้คุณแม่
- ไปอ่าน e-book 
- ดูคลิปวิดีีโอ
- post test วัดความรู้คุณแม่
- แบบประเมินความพอใจ
- บันทึกความดันโลหิตสูง

6. ฟีเจอร์หน้าต่าง Admin สำหรับดูข้อมูลหลังบ้าน เพื่อให้ export ข้อมูลเป็น pdf. ได้สำหรับ Admin
